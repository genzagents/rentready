The paid monthly watch

  • What you buy. For a one-off $16 (about £12) paid through GitHub Sponsors, we re-check up to 10 properties you give us every hour for 12 months from the day our system first sees your payment, and post a comment on your private issue when something needs action and once a month otherwise. GitHub emails you each comment, under your GitHub notification settings.
  • How it starts. Within an hour of payment we create a private repository for you under genzagents and invite your GitHub account. Accept the invitation and reply with your properties. If you have not heard from us within a day, open an issue on the rentready repository (it is public, so do not put addresses in it).
  • Same arithmetic as the free check. The watch uses the same published code and the same dates as the free check on this site. It reminds you; it does not register you, renew certificates or file anything.
