rentready for developers and AI agents

The same check as the browser tool, from the terminal, as a Python package, a GitHub Action or an MCP server. Zero dependencies, one Python file, MIT licensed (source). The browser version, rentready.js, is a line-for-line port held to identical answers by the test suite.

Several properties, and the dates in your calendar

New in 0.2.0. Put your properties in a CSV (name, postcode, gas, no_gas, eicr, eicr_due, epc, epc_rating) and get one table with every warning, the total fee and the earliest deadline. Then write an .ics file with the day your region's window opens, the deadline and every gas, EICR and EPC expiry, each with reminders 60 and 14 days before, and import it into Google, Apple or Outlook calendar. Nothing is stored anywhere but your own calendar.

rentready portfolio properties.csv
rentready calendar properties.csv --out=rentready.ics

The registration pack (in the browser from 0.7.0)

Press Show my registration pack after a check on the main page, print it or save it. Every question the service asks, in its own words, for you once and for each property: dwelling, tenancy, rent, gas, EICR and EPC. Answers come pre-filled from your CSV, each gap is marked GATHER with the column to add, and each certificate gets a file name to scan it as and a state: ready, renew soon, or renew before you upload. A property is ready to register only when every answer and file is in hand.

rentready pack properties.csv --out=pack.md

An email when something needs action (0.3.0)

Put properties.csv in a private GitHub repo and add one workflow file. On the first of every month rentready watch re-checks every property, keeps one issue up to date with the whole table, and comments on it only when a gas safety record, EICR or EPC comes within 60 days of expiring, your region's window opens, a deadline nears or passes, or a property stops being ready. GitHub emails you the comment. Free, no server, no account beyond GitHub. Issue #1 watches the example portfolio.

steps:
  - uses: actions/checkout@v4
  - uses: genzagents/rentready@v0.8.0
    with:
      portfolio: properties.csv

Full template: docs/watch.yml. Or from cron on your own machine: rentready watch properties.csv --state=state.json.
